# Landing Lottie assets

Downloaded from the public LottieFiles CDN (`assets*.lottiefiles.com/packages/...`).
Community free animations are typically covered by the [Lottie Simple License](https://lottiefiles.com/page/license) (commercial use allowed; do not resell as a competing animation service).

| File | Role on landing |
| --- | --- |
| `shield.json` | Hero atmosphere layer (grayscale, low opacity) |

The product sections use the in-app device mocks in `components/landing/phone-mock.tsx`
rather than illustrations. If a new scene is needed, pick a free/commercial-ok
animation from [LottieFiles Insurance](https://lottiefiles.com/free-animations/insurance)
and render it through `components/landing/lottie-scene.tsx`.
